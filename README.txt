ILIMIBRIDGE KEBBI MULTI-PAGE PROTOTYPE
Files: index.html, courses.html, quiz.html, teachers.html, about.html, style.css, script.js.
In Spck Editor create a project, then create each file with the exact filename and paste the matching contents. Keep all files in the same project folder. Open index.html and Preview.
The quiz contains five questions. The teacher suggestion form stores data only in this browser and does not send it to a server. This is a prototype, not a live platform with accounts or cloud storage.
